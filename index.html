지도는 OpenStreetMap과 Leaflet을 사용하며 Google Maps API 키나 결제 계정이 필요하지 않습니다. 장소 검색은 OpenStreetMap의 공개 검색 서비스를 사용하며 자동완성 없이 직접 검색할 때만 요청합니다.

친구들과 실시간으로 공유하려면 Firebase 프로젝트의 Firestore Database를 만들고, Firebase 웹 앱 설정 JSON을 아래에 붙여넣으세요. Firebase는 결제 계정을 연결하지 않은 Spark 무료 요금제로만 사용하세요. Firestore 보안 규칙도 설정해야 합니다.
